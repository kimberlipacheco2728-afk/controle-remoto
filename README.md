# 📱 Controle Remoto - App Inventor

Aplicativo mobile de controle remoto desenvolvido no **MIT App Inventor** como projeto inicial do curso de Desenvolvimento Mobile.

## 🚀 Funcionalidades
- Interface intuitiva com botões de comando para controle remoto.
- Lógica de programação desenvolvida em blocos.

## 🛠️ Tecnologias Utilizadas
- **MIT App Inventor** (Design de interface e programação em blocos)

## 📂 Como abrir o projeto
1. Baixe o arquivo `.aia` disponível neste repositório.
2. Acesse o [MIT App Inventor](https://appinventor.mit.edu/).
3. Clique em **Projetos** > **Importar projeto (.aia) do meu computador** e selecione o arquivo baixado.
